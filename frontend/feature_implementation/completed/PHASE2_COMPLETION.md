## Key Implementation Details

### Race Condition Prevention
Uses `FOR UPDATE` lock on chat row when updating message count:
```sql
SELECT * FROM rag.chats WHERE id = $1 FOR UPDATE
```

### Summarization Strategy
- Triggers every 30 messages (at 31, 61, 91...)
- Uses Claude to generate concise summary
- Marks old messages as `is_summarized = true`

### Title Generation
- First meaningful message (skips greetings like "hi", "hello")
- Generated by Claude from message content
- Real-time update via callback to sidebar

### Fresh Page on Load
- Like ChatGPT/Claude behavior
- No chat selected initially
- Chat created on first message send
